# مرجع الفيزياء والكهرباء والإلكترونيات للطلبة
Physics, Electricity, and Electronics Student Reference

تطبيق ويب مرجعي خفيف وعالي الدقة، مصمم للطلبة والمهندسين. يشتغل مباشرة وبشكل كامل دون اتصال بالإنترنت (Offline) بمجرد النقر المزدوج على `index.html` في أي متصفح ويب، دون الحاجة لأي خادم أو تثبيت مكتبات خارجية.

---

## طريقة تشغيل التطبيق

1. افتح مجلد `physics-reference`.
2. انقر نقراً مزدوجاً على ملف `index.html` (أو اسحبه داخل متصفح مثل Chrome أو Edge أو Firefox أو Safari).
3. يعمل التطبيق محلياً بالكامل عبر بروتوكول `file://`.
4. يمكنك تبديل لغة الواجهة بين العربية والإنجليزية عبر زر التبديل أعلى الصفحة، وسيتم حفظ اختيارك تلقائياً.
5. لتشغيل صفحة الاختبارات الآلية، افتح ملف `tests/tests.html`.

## كيفية إضافة وحدة أو ثابت جديد

### 1. إضافة وحدة قياس جديدة:
افتح ملف `data/units.js`، وابحث عن الفئة المناسبة (مثلاً `length` أو `mass`) داخل المصفوفة `REF.unitCategories`. أضف عنصراً جديداً إلى مصفوفة `units` الخاصة بتلك الفئة:

```javascript
{
  id: "myunit",                               // معرّف فريد للوحدة
  name: { ar: "اسم الوحدة", en: "Unit Name" }, // الاسم باللغتين
  symbol: "sym",                              // الرمز الدولي
  toBase: 0.12345,                            // معامل الضرب للتحويل للوحدة الأساسية
  exact: true                                 // true إذا كان المعامل دقيقاً بالتعريف، أو false إذا كان مقيساً
}
```

### 2. إضافة ثابت فيزيائي جديد:
افتح ملف `data/constants.js`، وأضف كائناً جديداً داخل مصفوفة `REF.constants`:

```javascript
{
  name: { ar: "اسم الثابت", en: "Constant Name" },
  symbol: "k_c",                              // رمز الثابت
  value: "1.234567e-12",                      // القيمة بصيغة نصية للنسخ
  valueNum: 1.234567e-12,                     // القيمة كرقم للحسابات
  unit: "J/mol",                              // وحدة SI
  exact: false,                               // هل هو دقيق بالتعريف أم مقاس؟
  uncertainty: "(15)",                        // الشك القياسي في آخر رقمين إن وجد
  note: { ar: "ملاحظة توضيحية", en: "Note" }
}
```

## مميزات تقنية وتصميمية

- **أداء خفيف وفوري:** لا يعتمد على أطر عمل ثقيلة أو طلبات شبكة خارجية.
- **التزام كامل بالدقة العلمية:** تطبيق إعادة تعريف وحدات النظام الدولي SI الصادرة عام 2019 وقيم CODATA 2022.
- **عرض الأرقام والرموز:** تظهر الرموز والمعادلات والأرقام دائماً من اليسار إلى اليمين (LTR) لمنع تشوه العمليات الرياضية داخل الواجهة العربية.
